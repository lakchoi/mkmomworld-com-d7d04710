## 목표
참여 신청 폼이 제출될 때마다 관리자(mk.momworld@gmail.com)에게 자동으로 알림 이메일이 전송되도록 설정합니다.

## 진행 단계

### 1. 이메일 발송 도메인 설정
`mkmomworld.com` 기반의 발송 도메인(예: `notify.mkmomworld.com`)을 설정합니다. 설정 다이얼로그가 표시되면 진행해주세요. DNS 검증이 완료되면 이메일이 정상 발송됩니다 (검증 진행 중에도 코드는 미리 준비됩니다).

### 2. 이메일 인프라 구축
이메일 발송을 위한 큐 시스템, 발송 로그, 수신 거부 관리 등의 백엔드 인프라를 자동으로 구성합니다.

### 3. 관리자 알림 이메일 템플릿 생성
신청자의 정보(이름, 연락처, 이메일, 메시지)가 포함된 깔끔한 한글 알림 이메일 템플릿을 사이트 디자인(다크 네이비/시안)에 맞춰 제작합니다.

**이메일 내용 예시:**
- 제목: `[맘월드] 새로운 참여 신청이 도착했습니다`
- 본문: 신청자 이름, 연락처, 이메일, 메시지, 신청 시각

### 4. 신청폼 트리거 연결
`ContactSection.tsx`에서 신청 데이터가 Supabase에 저장된 직후, 관리자에게 알림 이메일을 자동 발송하도록 연결합니다.

## 기술 세부사항
- Lovable Cloud 내장 이메일 시스템 사용 (외부 서비스/API 키 불필요)
- 발송 도메인: `notify.mkmomworld.com` (사용자 도메인 입력에 따라 변경 가능)
- 수신자: `mk.momworld@gmail.com` (고정)
- 템플릿: `admin-contact-notification` (React Email)
- 트리거: `contact_submissions` insert 직후 클라이언트에서 `send-transactional-email` 호출
- 멱등성 키: `contact-notify-{submission_id}` 로 중복 발송 방지

## 참고
- DNS 전파에는 최대 72시간이 소요될 수 있으나, 보통 수 분 내 완료됩니다.
- 검증 완료 전까지 이메일은 큐에 저장되었다가 검증 후 자동 발송됩니다.
- 향후 신청자 본인에게도 확인 이메일을 보내고 싶다면 추가로 요청해주세요.
